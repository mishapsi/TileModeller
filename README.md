## 🧩 Tileset-Based Modeling Plugin for Godot

A tileset-based modeling plugin built directly inside **Godot**.  
This project is a fork of **[GodotNode2Tile](https://github.com/QJPG/GodotNode2Tile)** and is heavily inspired by **Crocotile3D**.

**Tested on Godot 4.5**

---

## Shortcuts
 - 'R' to rotate tiles
 - 'T' in Quad Split mode to flip quad triangulation

---

## Features

- Autotiling  
- Custom Quad Shapes  
- Vertex Editing  
- Grid-Based Snapping  
- Multiple Tilesets
